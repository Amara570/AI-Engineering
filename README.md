# AI Engineering

This repository is my AI Engineering learning journey. It contains practical implementations, experiments, and notes as I build my understanding of modern AI systems.

## Repository Structure

- `fastapi/` - API development and model-serving projects with FastAPI.
- `docker/` - Containerization examples and Docker configurations.
- `ci_cd/` - Continuous integration and deployment workflows.
- `pytorch/` - Deep learning implementations and experiments with PyTorch.
- `transformers/` - Work with transformer architectures and libraries.
- `llm/` - Large language model projects, exercises, and integrations.
- `embeddings/` - Text and data embedding experiments and utilities.
- `rag/` - Retrieval-augmented generation implementations.
- `agents/` - AI agent patterns, tools, and workflows.
- `evaluation/` - Evaluation methods, metrics, and testing for AI systems.
- `notes/` - Learning notes, references, and summaries.
- `experiments/` - Exploratory experiments and prototypes.
